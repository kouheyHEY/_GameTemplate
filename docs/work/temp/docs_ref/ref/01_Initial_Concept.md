# 1. 初期構想書 (Initial Concept: "The Terminal")

**～ZINE / 開発後記 掲載用セクション～**

> **プロジェクト・コードネーム**: `Console Psycometrist`
> **コンセプト**: 「コンソールを通して人の思いを読み取る」
> **背景**:
> システムエンジニアにとって最も身近な道具である「ターミナル（コンソール）」を、物語の舞台として再定義する。グラフィックを極限まで削ぎ落とし、等幅フォントとカーソルの点滅だけでプレイヤーの没入感をコントロールする。
> **美学的目標**:
>
> - **情報の等価性**: システムメッセージも、キャラクターの独白も、同じフォントで表示することで「現実とデータの境界」を曖昧にする。
> - **タイポグラフィの美**: カーニング、行間、文字の出現速度にこだわり、テキストそのものを「演出」に昇華させる。
> - **ミニマリズム**: 色数を制限し（Amber, Green, White）、かつての80年代コンピュータのような「レトロ・フューチャー」を再現する。
