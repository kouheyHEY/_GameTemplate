# 2026-02-19 入力欄の視認性改善

## 変更の背景

コマンド入力時にソフトキーボードが出現すると、入力欄が画面上部にスライドします。
この際、入力欄の文字が背面のログテキストと重なってしまい、著しく視認性が低下する問題がありました。
ユーザーからの要望により、入力エリアに背景（白枠付き黒背景）を追加してこの問題を解決することになりました。

## 変更内容

### 1. `TerminalScene.ts` の UI構造変更

- `inputDisplay`（テキストオブジェクト）を直接操作するのではなく、新しく `inputContainer`（コンテナ）を作成し、その中に入力要素をまとめました。
- コンテナ内には以下の2つの要素を配置しました：
    1.  **背景矩形**: 黒色（#000000）の塗りつぶしに、白（#FFFFFF）の2px枠線を設定。
    2.  **入力テキスト**: `inputDisplay`。背景色を削除し、コンテナ内での相対座標に配置。

### 2. アニメーションロジックの修正

- `VirtualKeyboard` の開閉時にY座標をアニメーションさせる対象を、`inputDisplay` から `inputContainer` に変更しました。
- これにより、テキストだけでなく背景も含めた入力エリア全体がスムーズに移動するようになりました。

### 3. 表示切替の変更

- 入力モードの有効化・無効化（`enableInputMode`, `disableInputMode`）において、表示切り替えの対象を `inputContainer` に変更しました。

## 結果

コマンド入力モードになると、画面下部（またはキーボード展開時はキーボード上部）に明確な枠で囲まれた入力エリアが表示されるようになりました。
これにより、背面にどれだけ文字が表示されていても、入力中のコマンドがはっきりと読み取れるようになりました。
