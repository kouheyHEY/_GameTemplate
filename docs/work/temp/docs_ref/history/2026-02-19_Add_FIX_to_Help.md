# 2026-02-19 コマンドリストへのFIX追加

## 変更の背景

ユーザーからの追加要望により、初期状態（`mail_001`）で `FIX` コマンドもヘルプに表示されるように変更しました。
これにより、プレイヤーは必要なコマンド群を最初から確認できるようになります。

## 変更内容

- `public/data/mail_list.json`:
    - `mail_001`（初期訓練）の `unlockCommands` に `cmd_fix` を追加しました。
    - `mail_002`（スクラップ・ロジック）の `unlockCommands` から重複する `cmd_fix` を削除しました。

## 結果

HELPコマンドを実行すると、リストに `FIX` も含まれるようになります。
