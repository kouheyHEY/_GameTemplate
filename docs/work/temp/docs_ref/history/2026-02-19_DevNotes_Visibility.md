# 2026-02-19 開発者用メモのシナリオ解禁条件の整理

## 変更の背景

開発者用のヒントメモ（`ep_dev_secret_notes.json`）には、全エピソードのネタバレが含まれています。
まだプレイしていないエピソードのヒントや答えが最初から見えてしまうと、ネタバレになるだけでなく、プレイヤーの混乱を招く恐れがありました。
そのため、ユーザーからの要望により、**未クリアのエピソードに関するヒントファイルはリストに表示されない**ようにし、ネタバレを防止する仕組みが必要でした。

## 変更内容

### 1. `VirtualFile` 型定義の拡張

- `src/game/types/ProgressionTypes.ts` に `requiresCompletedEpisodeId` プロパティを追加しました。
- これにより、特定のファイルに対して「閲覧に必要なクリア済みエピソードID」を設定できるようになりました。

### 2. ファイル可視性ロジックの実装

- `src/game/scenes/TerminalScene.ts` に `getVisibleFiles(item)` ヘルパーメソッドを追加しました。
- このメソッドは、現在の進行状況（`registry.get("completed_episodes")`）と照らし合わせ、閲覧条件を満たすファイルのみをフィルタリングして返します。
- 以下のコマンド・機能でこのメソッドを使用するように変更しました：
    - `LIST` コマンド: 条件を満たさないファイルは一覧に表示されません。
    - `READ` コマンド: 条件を満たさないファイルを指定しても "FILE NOT FOUND" となり、アクセスできません。
    - `TAB` キー補完: 条件を満たさないファイルはオートコンプリートの候補に出現しません。

### 3. データファイルの更新

- `public/data/episodes/ep_dev_secret_notes.json` の各ログファイル定義に `requiresCompletedEpisodeId` を追加しました。
- 各ログファイルは、その内容に関連するエピソード（またはその前提エピソード）をクリアしていないと表示されません。

## 設計判断

- **「存在を隠蔽する」方針**: 単に読めなくするだけでなく、リストや補完候補からも除外することで、ファイルの存在自体を隠蔽しました。これにより「まだ何かある」という不要なノイズを排除し、現在の進捗に集中できるようにしました。
- **汎用性の確保**: `ep_dev_secret_notes` 専用のハードコードではなく、型定義と汎用ロジックとして実装したため、今後他のシナリオで同様の「条件付きファイル」を出したい場合にも流用可能です。

## 今後の課題

- 現在は `requiresCompletedEpisodeId` のみが条件ですが、より複雑な条件（特定のアイテム所持など）が必要になった場合は、条件判定ロジックを拡張する必要があります。
