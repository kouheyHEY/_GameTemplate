# 2026-02-18 シナリオデータ修正とロジック整合性の確保

## 変更の背景

シナリオレビューにおいて、以下の問題が特定されたため修正を行いました。

1. `ep_01_scrap_logic`: `FIX` コマンドの引数となる「YOSHIYOSHI」のヒントが直感的でなく、クリア困難である。
2. `ep_buggy_hero`: テキスト内に誤字「ハンドルメーム」が存在する。
3. `ep_challenge`: パズルの論理的解（Tribonacci数列、2進数加算）と、設定されていた正解IDが不一致である。

## 変更内容

### 1. [ep_01_scrap_logic.json] ヒントの明確化

- **変更前**: `『よしよし』と声をかけながら`
- **変更後**: `『よしよし (YOSHI-YOSHI)』と声をかけながら`
- **目的**: プレイヤーがコマンド引数としてローマ字入力を想起しやすくするため。

### 2. [ep_buggy_hero.json] 誤字修正

- **変更前**: `ハンドルメーム：RED_PHOENIX`
- **変更後**: `ハンドルネーム：RED_PHOENIX`
- **目的**: テキストの品質向上。

### 3. [ep_challenge.json] 正解IDの論理整合

- **変更前**: `correctAnswer: "45PPY"`
- **変更後**: `correctAnswer: "4435PPY"`
- **詳細**:
    - Q1 (Tribonacci): 0,0,1,1,2,4,7,13,24 -> 次は **44**
    - Q2 (Binary): 10110(22) + 1101(13) = **35**
    - Q3 (Initials): **P**ASSION, **P**OTCHI, **Y**OSHIYOSHI -> **PPY**
    - 結合解: **4435PPY**

## 設計判断

- **難易度調整**: `ep_01` は序盤のシナリオであるため、コマンド入力の楽しさを優先し、過度な推測を要求しないようにヒントを緩和しました。
- **論理の優先**: `ep_challenge` は「最終試練」としての性質上、プレイヤーの計算結果とシステム判定が厳密に一致する必要があります。曖昧な正解（45など）を許容せず、正確な計算結果を正解としました。

## 今後の課題

- 他のシナリオについても、プレイヤーのフィードバックがあれば随時ヒントの調整を行う可能性があります。
