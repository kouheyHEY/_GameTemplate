# シナリオテキストのスタイル変更：より直接的・システム的な表現へ

## 概要

ユーザーからの要望に基づき、全11エピソードのシナリオテキスト（`public/data/episodes/*.json`）をリライトしました。
従来の「文学的・小説的」な表現を排除し、「より直接的・システム的」な表現に変更しました。

## 変更の背景

- **課題**: 従来のテキストは感情描写や比喩が多く、ハッキング/解析シミュレーターとしての「冷徹さ」や「プロフェッショナル感」がやや希薄だった。
- **目的**: プレイヤーが「システムログ」や「業務報告書」を読んでいる没入感を高めるため、テキストのトーン＆マナーを統一する。

## 主な変更点

### 1. ナレーターの廃止とシステムログ化

- **Before**: 管理官や謎のナレーターが語りかけるスタイル（例：「深淵へようこそ。ここは...」）
- **After**: システムメッセージや業務連絡としての記述（例：「CONNECTION ESTABLISHED. TARGET: SECTOR-Z」）

### 2. コンテンツの簡潔化

- **Before**: 状況や感情を細かく説明する文章（例：「彼は一人ぼっちじゃなかったんですね。誰かにとってのヒーローだったんです」）
- **After**: 事実と分析結果のみを提示するスタイル（例：「ANALYSIS: COMPLETE. 対象は多数ユーザーの精神的支柱として機能」）

### 3. 対象ファイル

- `ep_00_tutorial.json`
- `ep_01_scrap_logic.json`
- `ep_challenge.json`
- 他、全8エピソードファイル

## 設計判断

この変更により、プレイヤーは「物語を読まされる」受動的な立場から、「断片的なデータから真実を読み取る」能動的な解析官としての体験が強化されることを意図しています。感情的なカタルシスは、説明されるものではなく、プレイヤー自身がログの行間から見出すものへと構造を変化させました。
