# サウンドデザイン計画 (Sound Design Plan)

## 1. コンセプト

**「冷たく静かな、しかし没入感のあるハッキング端末」**
プレイヤーが孤独なハッカー（あるいはサイコメトリスト）として、深夜に端末に向かい合っている空気感を音で演出する。
過度なゲーム的演出音は避け、現実的な「マシンの動作音」と「UIのフィードバック」を主軸にする。

## 2. 実装予定SEリスト

### 基本操作 (Priority: High)

| ID             | 名前         | イメージ                                            | 使用箇所                                   |
| -------------- | ------------ | --------------------------------------------------- | ------------------------------------------ |
| `se_key_type`  | キータイプ音 | メカニカルキーボードの「カチャ」という軽い音        | 文字入力時（ランダムピッチで変化をつける） |
| `se_key_enter` | 決定/送信    | 「カターン！」という少し重い打鍵音 + 電子的な送信音 | Enterキー押下時、コマンド実行時            |
| `se_delete`    | 削除         | 高速な「カカカ」またはテープの巻き戻し音            | Backspace時                                |
| `se_cursor`    | カーソル移動 | 短く鋭い電子音（Blip）                              | 十字キーでの履歴選択、選択肢移動時         |

### システムフィードバック (Priority: Medium)

| ID             | 名前       | イメージ                                        | 使用箇所                             |
| -------------- | ---------- | ----------------------------------------------- | ------------------------------------ |
| `se_error`     | エラー     | 低いブザー音、または「Access Denied」的な警告音 | 無効なコマンド入力時、アクセス拒否時 |
| `se_success`   | 成功/解除  | 明るく短いチャイム、またはロックが外れる機械音  | 正解入力時、暗号解除時               |
| `se_mail_recv` | メール着信 | 控えめな通知音                                  | 新着メール受信時                     |
| `se_boot`      | 起動音     | HDDのスピンアップ音、BIOSビープ音               | ゲーム起動時、TitleScene             |

### 環境音/BGM (Priority: Low)

| ID            | 名前           | イメージ                                             | 使用箇所                                 |
| ------------- | -------------- | ---------------------------------------------------- | ---------------------------------------- |
| `bgm_ambient` | サーバーノイズ | 低周波のファンノイズ、電子機器の駆動音（ハムノイズ） | 常時ループ再生（集中力を削がない程度に） |

## 3. 実装方針

1.  **SoundManagerの作成**:
    - PhaserのSoundシステムをラップし、音量調整や同時発音数制御を行うクラスを作成する。
    - 特にタイピング音は高速で連打されるため、前の音を止めずに重ねるか、間引き処理が必要。

2.  **アセットの調達**:
    - フリー素材サイト（OtoLogic, Maoudamashii, Freesound.org等）から収集。
    - または、Synth（sfxr等）でレトロな電子音を生成する。

3.  **適用**:
    - `TerminalScene` の `handleVirtualKey`, `processCommand` 等にフックして再生する。
