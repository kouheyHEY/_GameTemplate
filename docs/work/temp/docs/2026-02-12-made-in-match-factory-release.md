# [JP] 『Made in Match Factory』をリリースしました！

本日、パズルでゲームを生産するシミュレーションパズルゲーム、**『Made in Match Factory』** をリリースしました！

ブラウザ版と、Windows向けのダウンロード版の両方を公開しています。
ぜひ、あなたの手で最高のゲームタイトルを生産してください！

---

## 🎮 ゲームの概要

**「パズルでゲームを『生産』せよ！」**

あなたはゲーム工場の工場長です。
ベルトコンベアから流れてくる「企画」「プログラム」「グラフィック」「サウンド」といったリソースタイルを、マッチ3パズルの要領で並べて消し、新たなゲームタイトルを次々と生産して出荷します。

### 特徴

- **パズル × 工場シミュレーション**: 単に消すだけでなく、効率よく「製品（ゲーム）」を完成させる戦略性があります。
- **直感的な操作**: マウスのドラッグ＆ドロップだけで遊べる簡単操作。
- **心地よいリズム**: 工場の稼働音とBGMが刻むリズムに乗って、爽快な連鎖を楽しんでください。

# [EN] Released: Made in Match Factory (v1.0)

I am excited to announce the release of **Made in Match Factory**, a simulation puzzle game where you produce games through puzzles!

Both the browser version and the downloadable Windows version are available now.
Please produce the best game titles with your own hands!

---

## 🎮 Game Overview

**"Produce games with puzzles!"**

You are the manager of a game factory.
Align and clear resource tiles like "Planning," "Programming," "Graphics," and "Sound" flowing from the conveyor belt, just like a match-3 puzzle, to produce and ship new game titles one after another!

### Features

- **Puzzle x Factory Simulation**: A fresh twist on the classic match-3 formula where you manage production lines. It's not just about clearing tiles; it's about efficiently completing products (games).
- **Intuitive Controls**: Simple drag-and-drop mechanics allow anyone to jump in immediately.
- **Rhythmic Gameplay**: Get into the flow with a satisfying, factory-inspired rhythm.

## 📝 About Development

This game was developed using Phaser 3 (TypeScript) + Electron as part of a personal "2-week game dev challenge".
I have also published a development postmortem (in Japanese), so if you are interested in the technical details, please check it out.
