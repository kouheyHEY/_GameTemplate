■ゲーム概要
本ゲームは、Phaser 3で開発されたAIをテーマにしたゲームです。3マッチパズルでモジュールと呼ばれるユニットを消去し、さまざまなノルマ(決められたゲームの一定数の生産)をクリアしていきます。

■操作方法
モジュールの入れ替え:
    ・入れ替え元と入れ替え先のモジュールを順番に選択する
    ・入れ替え元のモジュールを、入れ替え先の方向にスワイプする
