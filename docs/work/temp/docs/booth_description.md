# Booth 商品説明 (Markdown)

## キャッチコピー

**パズルでゲームを「生産」せよ！ 工場経営パズルシミュレーション**

## 概要

『Made in Match Factory』は、マッチ3パズルとゲーム開発シミュレーションが融合した、新感覚のパズルゲームです。

あなたはゲーム工場の工場長。
ベルトコンベアから流れてくる「企画」「プログラム」「グラフィック」「サウンド」といったリソースタイルを並べて消し、最高のゲーム・タイトルを次々と生産して出荷しましょう！

**※本作はWindows用のダウンロード版です。**
ブラウザ版はitch.ioにて公開しています。

## ゲームの特徴

- **パズル × 工場シミュレーション**
  おなじみのマッチ3パズルに「生産」というスパイスを加えました。ただ消すだけでなく、効率よく製品（ゲーム）を完成させる戦略性が求められます。

- **直感的な操作と爽快感**
  複雑なルールは不要。マウス操作だけで、連鎖がつながる爽快感を味わえます。

- **心地よいリズム**
  工場の稼働音のような、リズミカルなBGMとSEで、不思議な没入感をお楽しみいただけます。

## 動作環境

- OS: Windows 10 / 11 (64bit)
- CPU/メモリ: 一般的なPCであれば動作します
- ストレージ: 約150MB以上の空き容量

## 遊び方

1.  ダウンロードしたzipファイルを解凍してください。
2.  フォルダ内の `MadeInMatchFactory.exe` をダブルクリックして起動します。
3.  画面の指示に従ってプレイしてください。マウスのみで操作可能です。
