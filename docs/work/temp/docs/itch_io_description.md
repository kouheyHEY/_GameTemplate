# itch.io Description (Markdown)

## [Japanese]

### タイトル

**Made in Match Factory**

### 概要

**「パズルでゲームを『生産』せよ！」**

『Made in Match Factory』は、マッチ3パズルとゲーム開発シミュレーションが融合した、新感覚の工場経営パズルゲームです。

あなたはゲーム工場の工場長。
次々と流れてくる「企画」「プログラム」「グラフィック」「サウンド」といったリソースタイルを並べて消し、最高のゲーム・タイトルを完成させて出荷しましょう！

### 特徴

- **パズル × 工場シミュレーション**: おなじみのマッチ3パズルに「生産」というスパイスを加えました。ただ消すだけでなく、効率よく製品（ゲーム）を完成させる戦略性が求められます。
- **直感的な操作と爽快感**: 複雑なルールは不要。直感的な操作で、連鎖がつながる爽快感を味わえます。
- **心地よいリズム**: 工場の稼働音のような、リズミカルなパズル体験をお楽しみください。

### パッケージ版について

ブラウザ上で遊べるほか、**Windows向けのダウンロード版**も配布しています。
より快適な動作で遊びたい方は、ダウンロード版をご利用ください。

### 操作方法

- **マウス操作**: タイルをドラッグ＆ドロップして入れ替えます。
- **マッチ**: 同じ種類のタイルを3つ以上並べて消します。

## [English]

### Title

**Made in Match Factory**

### Overview

**"Produce games with puzzles!"**

**Made in Match Factory** is a unique puzzle game that blends match-3 mechanics with game development simulation.

You are the manager of a game factory.
Align and clear resource tiles like "Planning," "Programming," "Graphics," and "Sound" to produce and ship the best game titles!

### Features

- **Puzzle x Factory Simulation**: A fresh twist on the classic match-3 formula where you manage production lines. It's not just about clearing tiles; it's about efficiently completing products (games).
- **Intuitive & Satisfying**: Simple controls allow anyone to jump in immediately. Enjoy the thrill of setting up chains and combos.
- **Rhythmic Gameplay**: Get into the flow with a satisfying, factory-inspired rhythm.

### Downloadable Version

In addition to the browser version, a **standalone version for Windows** is available for download.
Please use the downloadable version for a smoother gameplay experience.

### Controls

- **Mouse**: Drag and drop to swap tiles.
- **Match**: Line up 3 or more tiles of the same type to clear them.
