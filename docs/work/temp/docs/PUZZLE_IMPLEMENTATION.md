# マッチ3パズル統合実装ドキュメント

## 📋 概要

AICreatorにマッチ3パズルゲームを統合し、パズルエリア（左側33%）とゲーム生産エリア（右側67%）の2つのエリアでゲームプレイができるようになりました。

## 🎮 ゲームフロー

```
[パズルエリア(左)]          [ゲーム生産エリア(右)]
┌─────────────┐            ┌──────────────┐
│ タイルを選択 │            │ モジュール配置│
│    ↓        │            │      ↓       │
│ 隣接と交換  │            │      ○       │
│    ↓        │            │      ○       │
│ マッチ検出  │──────→    │      ○       │
│    ↓        │ リソース    │      ↓       │
│ タイル消去  │  生成      │   AIコア     │
│    ↓        │            │      ↓       │
│ 落下＆補充  │            │  ゲーム生産  │
└─────────────┘            └──────────────┘
```

## 🎯 プレイ方法

### パズルエリア（左側）

1. **タイル選択**: タイルをクリックして選択（黄色の枠が表示）
2. **タイル交換**: 隣接するタイルをクリックして交換
3. **マッチ成立**: 同じ色のタイルが縦or横に3つ以上並ぶと消える
4. **リソース生成**: 消えたタイルの種類に応じて、ゲーム生産エリアのモジュールからリソースが生成される

### タイルの種類

- **青（ゲームモジュール）**: ロジックリソースを生成
- **赤（イラストモジュール）**: イラストリソースを生成
- **緑（サウンドモジュール）**: サウンドリソースを生成

### ゲーム生産エリア（右側）

- 既存のゲームシステムと同じ
- モジュールを配置してAIコアにリソースを送る
- パズルエリアでマッチが成立すると、対応するモジュールから追加でリソースが生成される

## 🏗️ アーキテクチャ

### デザインパターン

| パターン      | 適用箇所                    | 目的                                |
| ------------- | --------------------------- | ----------------------------------- |
| **Singleton** | AreaLayoutManager           | 画面レイアウト情報の一元管理        |
| **State**     | PuzzleState + PuzzleManager | パズルの状態遷移を厳格に管理        |
| **Observer**  | `puzzle:match` イベント     | パズル⇔ゲーム生産エリアの疎結合連携 |
| **Factory**   | PuzzleTileFactory           | タイル生成ロジックの集約            |
| **Prefab**    | PuzzleTile, PuzzleGrid      | 自己完結したUIコンポーネント        |
| **Manager**   | PuzzleManager               | 複雑なロジックをSceneから分離       |

### ファイル構成

```
src/
├── constants/
│   └── Puzzle.ts                     # パズル定数定義
├── core/managers/
│   ├── AreaLayoutManager.ts          # 画面分割管理（Singleton）
│   └── PuzzleManager.ts              # パズル全体統括
├── puzzle/
│   ├── PuzzleGrid.ts                 # グリッドUI（Container）
│   ├── PuzzleTile.ts                 # 個別タイルPrefab
│   ├── PuzzleTileFactory.ts          # タイル生成Factory
│   ├── MatchDetector.ts              # マッチ3検出ロジック
│   └── PuzzleState.ts                # State定義＋バリデーター
└── scenes/
    └── GameScene.ts                  # 統合・橋渡し
```

## 🔧 技術仕様

### パズル定数（PUZZLE）

```typescript
{
  GRID_SIZE: 8,           // 8×8グリッド
  TILE_SIZE: 60,          // タイルサイズ（px）
  MATCH_MIN: 3,           // 最小マッチ数
  SWAP_DURATION: 300,     // 交換アニメーション（ms）
  FALL_DURATION: 200,     // 落下アニメーション（ms）
  CLEAR_DURATION: 300,    // 消去アニメーション（ms）
  AREA_WIDTH: 600,        // パズルエリア幅（px）
  OFFSET_X: 30,           // 左端オフセット
  OFFSET_Y: 80,           // 上端オフセット
}
```

### 状態遷移

```
IDLE (アイドル)
  ↓ タイル選択
SELECTING (選択中)
  ↓ 隣接タイル選択
SWAPPING (交換中)
  ↓ 交換完了
MATCHING (マッチ検出・消去)
  ↓ 消去完了
FALLING (落下)
  ↓ 落下完了
REFILLING (補充)
  ↓ 補充完了（マッチがあれば再度MATCHING、なければIDLE）
```

### イベント連携

**イベント名**: `puzzle:match`

**ペイロード**:

```typescript
{
  moduleType: string,  // "game" | "illust" | "sound"
  count: number        // マッチしたタイル数
}
```

**処理フロー**:

1. パズルでマッチ発生
2. PuzzleManagerがイベントを発火
3. GameSceneがイベントをリスン
4. 対応するモジュールスロットを検索
5. リソースを生成してAIコアに送る

## 🧪 動作確認手順

### 1. サーバー起動

```bash
npm run dev
```

### 2. ブラウザで確認

- URL: http://localhost:5173/
- 画面が左右に分割されていることを確認

### 3. パズル動作確認

1. 左側エリアのタイルをクリック（黄色枠が表示）
2. 隣接するタイルをクリック（交換アニメーション）
3. 3つ以上揃うと消える（マッチフィードバック表示）
4. 新しいタイルが上から落ちてくる

### 4. 連携確認

1. 右側エリアにゲームモジュールを配置
2. パズルで青（ゲーム）タイルをマッチ
3. モジュールからAIコアにリソースが流れることを確認
