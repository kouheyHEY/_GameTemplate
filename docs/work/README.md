# 作業・一時ドキュメント (Work / Scratchpad)

このディレクトリは、現在進行中のタスクの設計、一時的なメモ、およびブレインストーミングのための作業領域です。

## ディレクトリ構成

- **`plan/`**: 現在着手している、または近日着手予定のタスクに関する具体的な手順書や下書き。
- **`history/`**: 過去に行ったブレインストーミングのログや、ボツになったアイデアのスクラップ。

## 運用ルール
「清書」する前の思考プロセスを記録するために使用します。有用な結論が得られた場合は、適切なカテゴリ（`common`, `game`, `app`）へ移動・整理してください。
