# 共通ドキュメント基盤 (Common Documentation)

このディレクトリには、すべてのゲームプロジェクトで共有される基盤となるガイドライン、テンプレート、および将来計画を格納します。

## ディレクトリ構成

- **`guide/`**: コーディング規約、GitHub 運用、新規プロジェクト開始手順などの共通ガイド。
- **`template/`**: 仕様書、報告書、README などの Markdown テンプレート。
- **`plan/`**: このテンプレート基盤（Core フレームワークや共通ドキュメント）自体の将来的な拡張計画。
- **`history/`**: テンプレート基盤自体の更新履歴。

## 運用ルール
ここでの変更は、すべてのプロジェクトに影響を与える可能性があるため、汎用性を重視して記述してください。
