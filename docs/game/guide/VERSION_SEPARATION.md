# 体験版とパッケージ版の分離

## 実装概要
AICreatorプロジェクトで確立された、体験版（デモ版）とパッケージ版（フル版）の機能分離アーキテクチャです。

## 主要コンポーネント

### 1. VersionManager
- 実行環境（Browser/Electron）の自動検出。
- アプリケーションバージョン（Demo/Package）の自動判定。
- シングルトンパターンによる一元管理。

### 2. 動的アセットロード (PreloadScene)
- バージョンに応じたアセットの動的ロード。
- パッケージ版専用アセット（BGM/SE/Assets等）の条件付きロード。

### 3. ローカルランキング機能 (LocalRankingManager)
- Electron IPCを通じたデータの永続化。
- トップ10の自動管理、ランクイン判定、クリア機能。

### 4. ギャラリー機能 (GalleryScene)
- 3つのタブ（BGM/SE/Assets）によるコンテンツ閲覧。
- パッケージ版専用コンテンツの試聴・プレビュー。

## 設計のメリット
- **関心の分離**: バージョン判定、データ管理、表示が完全に独立。
- **拡張性**: 新しいバージョンやプラットフォームへの対応が容易。
- **一貫性**: 同じコードベースで異なる機能セットを提供可能。
