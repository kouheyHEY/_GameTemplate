## 1. プロジェクトセットアップ

### 1.1 技術スタック選定

#### 推奨構成
- Phaser 3 (v3.60+)
- TypeScript
- Vite
- Electron (デスクトップ版)

### 1.2 ディレクトリ構造設計
本テンプレートの構造（`src/core` と `src/game` の分離）は、このガイドの設計思想に基づいています。

---

## 2. アーキテクチャ設計

### 2.1 設計原則
- **SOLID原則**: 単一責任、依存性逆転などを意識。
- **デザインパターン**: 
    - **State パターン**: シーンやキャラクターの状態管理。
    - **Factory パターン**: オブジェクト生成の隠蔽。
    - **Observer パターン**: イベントによる疎結合な通信。

### 2.2 Sceneの設計
Scene は表示とライフサイクル管理に徹し、ロジックは Manager クラスに委譲します。

## 3. 開発フェーズ
1. **プロトタイピング**: コアメカニクスの検証。
2. **アーキテクチャ構築**: 基盤システムの確立。
3. **コンテンツ実装**: UI、エフェクト、サウンド、チュートリアル。
4. **最適化とデバッグ**: パフォーマンス改善とバグ修正。

---

## 4. 実装パターン
- **Entity-Component アプローチ**: 機能を部品化。
- **データ駆動設計**: 設定値を外部化（JSON/TS定数）。
- **オブジェクトプール**: 頻繁な生成・破棄の最適化。
- **セーブ/ロード**: `localStorage` や `electron-store` の活用。

---

## 5. 最適化とデバッグ
- テクスチャアトラスの使用。

- デバッグコマンドの実装（`window.game` への露出）。
