# ゲーム開発知見 (Game Dev Knowledge)

このディレクトリには、Phaser 3 や一般的なゲームエンジンの実装パターン、UI デザイン、チュートリアル、デバッグ手法などのゲーム開発特有の知見を格納します。

## ディレクトリ構成

- **`guide/`**: 実装パターン（StateMachine, UI Components 等）の解説ガイド。
- **`template/`**: ゲームタイトル、ゲームデザインドキュメント (GDD) 等のテンプレート。
- **`plan/`**: 共通で使えるゲームシステムの将来的な設計案やアイデア。
- **`history/`**: このディレクトリ内のガイドやテンプレート自体の更新履歴。

## 運用ルール
プロジェクト横断的に役立つ知識や実装例を積極的に蓄積してください。
