# アプリケーション固有ガイド (App Specific Guides)

このディレクトリには、このプロジェクト固有の設計、仕様、または運用に関するガイドを配置します。

## 推奨されるコンテンツ

- **技術仕様書**: このプロジェクト特有のシステム設計やアルゴリズムの解説。
- **UI/UX仕様**: 画面遷移図やデザインガイドライン。
- **アセット管理**: プロジェクトで使用する特定のアセットの作成・導入手順。
