# 2026-02-18 シナリオ調整：深淵の暗号パズル変更

## 変更の背景

`ep_abyssal_cipher` の「Look-and-Say（見て言う）数列」は難易度が高く、プレイヤーにとって直感的でない可能性があるため、よりテーマ（システム・データ）に沿った「ランレングス符号化（定長圧縮）」のパズルへ変更しました。

## 変更内容

### [ep_abyssal_cipher.json] TEST_02 の差し替え

- **変更前**: Look-and-Say 数列 (1, 11, 21, 1211...)
- **変更後**: 2段階暗号（展開＋シフト）
    - **問題**: `C1 D2 O1`
    - **ルール1 (展開)**: 文字を数値分繰り返す (`C1 D2 O1` -> `CDDO`)
    - **ルール2 (シフト)**: アルファベット順で1つ進める (`CDDO` -> `DEEP`)
    - **正解**: `DEEP`
- **テキスト変更**:
    - 「ランレングス」等の専門用語を排除し、具体例(`A2 B1` -> `AAB` -> `BBC`)でルールを提示。
    - テーマ「深淵」に合わせ、解凍から「進化」へのプロセスを演出。

## 意図

「深淵（Abyssal）」というエピソードタイトルに対し、正解キーワードを「DEEP」とすることで、テーマとの親和性を高めました。また、圧縮・解凍という概念はプログラマブルな世界観により合致します。
