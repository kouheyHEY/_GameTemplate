# 2. 基本設計書 (Basic Design Document)

**～システム構成とUIの構造～**

### UIレイアウト構成

画面を3つの主要エリアに分割します。

| エリア名                  | 役割                                       | 視覚的特徴                                         |
| ------------------------- | ------------------------------------------ | -------------------------------------------------- |
| **Header (Status Bar)**   | 現在のディレクトリ、時刻、接続状態の表示。 | 反転文字（背景色あり）で情報を固定表示。           |
| **Main (Log View)**       | 物語（ログ）が流れるメインエリア。         | 上から下へテキストが流れ、溢れるとスクロールする。 |
| **Footer (Command Line)** | ユーザーの入力・選択待機場所。             | `> `（プロンプト）と点滅カーソルを表示。           |

### 主要システム・コンポーネント

1. **Terminal Container**: 全てのUIパーツを内包し、スキャンラインやノイズなどのポストエフェクトを一括適用する親要素。
2. **Scroll Manager**: テキスト行が増えた際、古い行をスムーズに上部へ移動させる制御ロジック。
3. **Command Dispatcher**: ユーザーの入力（キーボード/クリック）を解析し、適切な物語のフラグへ橋渡しする処理。
