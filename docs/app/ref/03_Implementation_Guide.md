# 3. 具体化指示書：UI実装編 (Implementation Guide)

**～Phaser 3 + TypeScript による実装ガイド～**

### 【実装ミッション 1】フォントとカメラの設定

- **等幅フォントの導入**: Google Fonts等から `JetBrains Mono` や `Share Tech Mono` などのMonospaceフォントをロードしてください。
- **解像度固定**: ピクセルパーフェクトな質感を出すため、スケーリングを `Phaser.Scale.FIT` に設定しつつ、レンダリングを `pixelArt: true` に設定してください。

### 【実装ミッション 2】Typewriter Component の作成

単なるテキスト表示ではなく、以下のプロパティを持つクラスを作成してください。

- `speed`: 文字出現速度（ms）。
- `isSkipping`: クリック時に一瞬で全表示するフラグ。
- `cursorCharacter`: 最後に表示される `_` や `█` の点滅制御。

### 【実装ミッション 3】コンソール風エフェクトの適用

以下の「味付け」を `Graphics` または `PostFX` で実装してください。

- **Scanlines**: 画面全体に薄い横線を1pxおきに描画。
- **Vignette**: 画面の四隅をわずかに暗くし、古いモニターの丸みを演出。
- **RGB Shift**: テキストがタイピングされる瞬間に、ごくわずかに色収差を発生させる。

### 【実装ミッション 4】入力待機インターフェース

- **選択肢の提示**:

```text
[1] サーバーを再起動する
[2] ログを破棄する
[3] 接続を切断する
> _
```

- **入力受付**: キーボードの `1`, `2`, `3` キー、またはテキストをクリックすることで `nextScene` を発火させる仕組みを実装してください。
