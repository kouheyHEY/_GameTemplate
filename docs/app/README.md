# プロジェクト固有ドキュメント (App Specific)

このディレクトリには、このプロジェクト固有の要件、仕様、および開発履歴を格納します。

## ディレクトリ構成

- **`guide/`**: プロジェクト固有の設計書、操作マニュアル、リリースノート。
- **`plan/`**: プロジェクトのロードマップ、TODO リスト、機能拡張の将来計画。
- **`history/`**: このプロジェクト自体の開発履歴（要件定義、設計判断、大規模実装ログ）。

## 運用ルール
プロジェクトが完了した際、将来の自分や他のメンバーが「なぜこうなったか」を理解できる詳細な記録を残してください。
